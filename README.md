# VKV Simple Tasks

A simple, mobile-friendly checklist web app developed for **Vivekananda Kendra Vidyalaya, Nalbari**.

## Features

- Create multiple checklists
- Add, edit, delete and complete tasks
- Quick checklist templates for common school activities
- Optional instructions for each checklist
- Calendar-based deadline selection
- Separate time selection
- Undo and redo
- Progress tracking
- Copy checklist as text
- Share an interactive checklist through a web link
- Checklists are automatically saved on the device
- Mobile-friendly interface
- VKV Nalbari branding

## Quick Templates

The app includes ready-to-use templates for:

- Daily Teacher Tasks
- Meeting Action Points
- Event Preparation
- Class Observation Follow-up
- Documents to Submit
- Shopping / Materials List

## Interactive Sharing

A checklist can be shared as a web link through WhatsApp, Telegram, email or other apps.

When the recipient opens the link, the checklist becomes interactive and is saved as an independent copy on the recipient's device.

Changes made by the recipient do not change the sender's original checklist.

## Privacy

The current version does not require login or an online database. Checklists are stored locally in the user's browser.
